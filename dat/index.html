Physics notes & formulas

fc = (c/2)·√((m/a)² + (n/b)²)  ·  λc = 2/√((m/a)² + (n/b)²)  ·  kc = 2π/λc
f₀ > fc (propagating): β = k₀√(1−(fc/f₀)²), λg = 2π/β, ZTE = η₀/√(1−(fc/f₀)²), ZTM = η₀·√(1−(fc/f₀)²)
f₀ < fc (evanescent): α = kc√(1−(f₀/fc)²), fields decay as e−αz — no power is delivered.

TE modes (Ez = 0), m,n ≥ 0, not both 0 (phasors ejωt−jβz, signs follow one common convention — only relative structure matters for the pattern):

HzH₀ cos(mπx/a) cos(nπy/b)
Ex(jωμ/kc²)(nπ/b)H₀ cos(mπx/a) sin(nπy/b)
Ey−(jωμ/kc²)(mπ/a)H₀ sin(mπx/a) cos(nπy/b)
Hx(jβ/kc²)(mπ/a)H₀ sin(mπx/a) cos(nπy/b)
Hy(jβ/kc²)(nπ/b)H₀ cos(mπx/a) sin(nπy/b)

The transverse E is proportional to ẑ × ∇tHz: it curls around the Hz extrema (swirl pattern) and vanishes wherever Hz is locally flat.

TM modes (Hz = 0), only m ≥ 1 and n ≥ 1:

EzE₀ sin(mπx/a) sin(nπy/b)
Ex−(jβ/kc²)(mπ/a)E₀ cos(mπx/a) sin(nπy/b)
Ey−(jβ/kc²)(nπ/b)E₀ sin(mπx/a) cos(nπy/b)
Hx(jωε/kc²)(nπ/b)E₀ sin(mπx/a) cos(nπy/b)
Hy−(jωε/kc²)(mπ/a)E₀ cos(mπx/a) sin(nπy/b)

Et ∝ ∇tEz: the arrows look radial, meeting the Ez cells head-on. Ez must be zero on all four walls while still varying inside — that is exactly why m,n ≥ 1.

  • Why TE₀₀ / TM₀₀ / TM₁₀ / TM₀₁ don't exist: TE₀₀ would make Hz constant ⇒ ∇tHz = 0 ⇒ every E component vanishes. For TM, one zero index makes Ez ≡ 0, and Hz = 0 by definition ⇒ no field. A hollow single-conductor guide cannot fall back on TEM either (that needs ≥ 2 conductors).
  • Dominant mode & mono-mode band: fc(TE₁₀) = c/2a is the smallest fc whenever a > b. With b ≤ a/2, the band c/2a < f < c/a carries TE₁₀ alone.
  • Degeneracy: fc depends only on (m, n, a, b) — so TE₁₁/TM₁₁, TE₂₁/TM₂₁ … are pairs with identical cutoff but different field structure.
  • Analogy: the longitudinal field plays the role of a rectangular drumhead: Ez (TM) is clamped at the rim (must vanish on the walls), and m, n count its nodal lines in each direction — 2-D standing waves, like two string harmonics at once.
  • Units & symbols: a, b in mm · f, fc in GHz · λ in mm · β in rad/m · α in Np/m (×8.686 → dB) · c = 299 792 458 m/s · η₀ = 376.73 Ω. Internally everything is converted to SI once, in kcOf().
  • Known idealizations: perfect conductors (no wall loss), lossless filling, one mode at a time (no superposition/beating).

Usage · README · self-check rubric

Run: open this single HTML file in a browser. Controls: family toggle → m, n sliders (0–5) → a, b sliders or a dimension preset → f₀ slider. Mode presets and the chart rows load modes instantly. Keyboard: focus any slider and use ←→; Tab reaches every control; chart rows are buttons.

  • Tangential E = 0 on every PEC wall for every rendered mode — checked analytically in the live “BC check” box and visually (arrows meet walls normally or vanish).
  • Units centralized (mm→m, GHz→Hz); spot-checked λg = 39.71 mm for TE₁₀ in WR-90 at 10 GHz against handbook values.
  • TE₀₀, TM₀₀, TM₁₀, TM₀₁ render an explicit “no field exists” state and are excluded from the chart and the game.
  • Raising m or n adds lobes/nodes (test log rows 2–3); fc rises with m, n.
  • TE₁₀ is dominant for a > b; re-verified for a < b and a = b (rows 9–10).
  • TM₁₁ is the lowest TM mode; TE₁₁/TM₁₁ degeneracy is marked in the chart.
  • Evanescent modes are labeled, show e−αz decay, and never claim to propagate.
  • Colorblind-safe colormap, status = color + text, reduced-motion respected, canvases have live ARIA descriptions.
